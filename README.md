#Objective
---
The objective of this project is to attempt to simulate the electron cloud of an atom according to the principles of Quantum Mechanics and the Schrodinger Wave Equation, 
which states that we can calculate the probability of finding an electron using its Quantum numbers, as well as its polar coordinates.

#Languages used 
---
The Language used to create 3d Plots of electron clouds is Python. Libraries used include numpy, Matplotlib, Scipy, Skimage and MPI4py
